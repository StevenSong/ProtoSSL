HEEDB case selector

  • Age / year / sex / site (top left): leave a box empty for no limit. Ranges include both ends. Setting an age limit leaves out ECGs with unknown age. Untick a sex or site to leave it out.
  • Label filter (left): click req to require a label or excl to exclude it. Choose whether a case must have all required labels or at least one of them. The numbers show how many matching ECGs carry each label.
  • Get a case: type an ECG ID and press Enter, or click Random match (R) for a random ECG that matches the filter. Use ← / → to go back and forward through the cases you have viewed.
  • Select: click Select case (S) to add the current ECG to your list, and type an optional note. Click it again to unselect.
  • Saving: your list is saved automatically in this browser on this computer. It survives closing the browser, but it is not visible from another browser or computer. Use Export CSV to send the list back, and Import to restore a list from an exported file.
  • Label sources: the physician overread, the original MUSE statement, and the ProtoECGNet fusion model's prediction. The model's probabilities are turned into yes/no at a per-label cutoff chosen on a separate validation set. Any source can drive the filter.
  • If the ECG does not display, use Open PDF to open it in a new tab. Chrome or Edge works best.
